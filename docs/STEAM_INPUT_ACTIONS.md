# Steam Input Action Names

Recommended Steam Input action names:

- Move
- Camera
- Confirm
- Cancel
- BraceletShot
- BraceletCharge
- Dodge
- TameScan
- Interact
- MaterializeRecall
- SlotPrevious
- SlotNext
- UseSupply
- Map
- LoreArchive
- Pause

Use action names instead of hard-coding controller buttons where possible. This helps support Xbox controllers, PlayStation controllers, Switch-style controllers, Steam Deck, and keyboard layouts.
